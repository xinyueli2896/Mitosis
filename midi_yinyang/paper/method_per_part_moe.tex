\label{sec:permod_moe}

Every transformer block ends in a sparsely gated mixture-of-experts
(MoE) feed-forward layer. It receives the attention sub-layer's output
$\tilde{\mathbf{h}}_p$ at position $p$, together with that position's
\emph{stream label} $s_p \in \{x, y\}$, and holds a pool of $E$
experts, each an ordinary two-layer network
$\mathrm{FFN}_i(\mathbf{h}) = \mathbf{W}^{(2)}_i
\sigma(\mathbf{W}^{(1)}_i \mathbf{h})$ with GELU $\sigma$ and inner
width $d_f$.

We route with a \emph{stream-specific} router: $\mathbf{G}^{(x)}$ and
$\mathbf{G}^{(y)}$, both $E \times d$, each scoring only the positions
of its own stream,
\begin{equation}
  \boldsymbol{\pi}_p
  = \operatorname{softmax}\bigl(\mathbf{G}^{(s_p)}\,
      \tilde{\mathbf{h}}_p\bigr)
  = \operatorname{softmax}\bigl(
      \mathbf{G}^{(s_p)}\tilde{\mathbf{c}}_p
    + \mathbf{G}^{(s_p)}\mathbf{s}_{s_p}\bigr).
  \label{eq:permod_router}
\end{equation}
The second form splits $\tilde{\mathbf{h}}_p = \tilde{\mathbf{c}}_p +
\mathbf{s}_{s_p}$ into a content component and a stream-conditional
offset, which the per-stream attention projections imprint on
everything they emit. Because $\mathbf{G}^{(x)}$ only ever scores
stream-$x$ positions, the term $\mathbf{G}^{(x)}\mathbf{s}_{x}$ is
identical for every input that router sees: a constant shift of its
logits. It can bias which experts stream $x$ prefers overall, but it
cannot make two stream-$x$ positions route differently. Routing
\emph{variation} within a stream is therefore content-driven by
construction, and no router capacity goes to re-deriving which stream a
position belongs to --- a bit the input already carries.

The pool itself stays shared and unassigned: both routers score the
same $E$ experts, so which ones a stream recruits --- and whether any
serves both, acting as an integrator --- is learned rather than
imposed. The designed contrast is with hard-partitioned
designs~\cite{moma}, which we ablate by masking each stream's logits to
a disjoint half of the pool: same parameters and activated compute, but
an integrator is no longer representable.

Each position is dispatched to its top-$k$ experts with renormalized
weights, and the mixture is added residually and layer-normalized. Load
is balanced with the auxiliary term of~\cite{fedus2022switch} at weight
$0.01$, computed \emph{within each pool} in the hard-partition arm,
where the all-expert form would demand a uniform load that the masked
routing cannot produce.

The routers are the layer's only addition: one bias-free $E \times d$
matrix per stream (${\approx}10^{-3}$ of the layer), with the expert
pool, the $k$ of $E$ activated per position and every other computation
untouched, so our routing ablations differ in the routing rule alone,
at parameter and compute parity. Both are initialized as copies of the
pretrained model's router and diverge only as their streams' gradients
differ. We use $E = 4$, $k = 2$, $d_f = 3d$.
